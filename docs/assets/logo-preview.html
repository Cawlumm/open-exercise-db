open-exercise-db — logo concepts

Three directions. Amber/slate palette, distinct from lyftr's cyan/slate so the two read as separate brands side by side. Hand-coded SVG, no external assets.

Concept A
Open plate
Weight plate drawn as a broken ring — the gap is the "open" cue, echoing OpenStreetMap/OpenFoodFacts' visual language. Most literal fit for "open data + fitness."
docs/assets/logo-a-open-plate.svg
Concept B
Barbell stack
Barbell whose plates double as stacked database discs — reads as both "lifting" and "database" at a glance. Closest sibling to lyftr's own barbell mark without copying it.
docs/assets/logo-b-barbell-stack.svg
Concept C
Bracket plate
Plate framed by code brackets — leans into the API-first identity and the developer-contributor audience rather than the gym side.
docs/assets/logo-c-bracket-plate.svg

Each shown full size and at ~62% (favicon/README scale) to check it holds up small, plus on a dark ground. Pick one and it gets copied to docs/assets/logo.svg (what the README already points at); the other two get deleted.
